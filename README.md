# Sick Day — surf rankings

Static page ranking NorCal and Oahu surf spots per day and time-of-day,
from open data (Open-Meteo swell/wind, NOAA tides). `rankings.json` is
regenerated several times daily by the (private) scoring pipeline.

Scores are 0–100; the threshold marks "worth rearranging your day."
Not affiliated with any forecast service. Surf at your own risk.
